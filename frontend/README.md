# OpenNewsletter — Frontend

React 18 + Vite + TypeScript + Tailwind app.

## Run

```bash
cd frontend
nvm use            # pick up .nvmrc → Node 20
npm install
npm run dev        # http://localhost:5173 — mock mode (see below)
```

No `nvm`? `brew install node` (macOS) gives a current Node 20.x that satisfies `.nvmrc` — skip `nvm use`. See [`../plans/13-dev-environments.md` §0](../plans/13-dev-environments.md#0-workstation-setup) for full first-time setup per OS.

### Mock mode vs real mode

- **`npm run dev`** loads `.env.development` (checked in, `VITE_USE_MOCKS=true`) and runs
  fully offline: `AuthProvider` reports a fake signed-in user and `apiFetch` is routed to
  the in-memory fixtures in `src/api/mockTransport.ts` instead of the network. No Cognito
  or backend setup needed — this is the fastest loop for UI work.
- **`make fe`** (from the repo root) runs `vite --mode dev`, which reads the gitignored
  `.env.dev` generated by `scripts/write_frontend_env.py` from real CDK outputs
  (`VITE_USE_MOCKS=false` there). This talks to a real Cognito user pool and a real API
  Gateway/Lambda backend — see [`../plans/13-dev-environments.md`](../plans/13-dev-environments.md)
  for how to stand that up.

## Stack notes

- **Routing**: React Router v6 data routers — see `src/App.tsx`.
- **Server state**: TanStack Query — hooks live in `src/api/queries.ts`.
- **Client state**: Zustand stores in `src/state/`.
- **Forms**: react-hook-form + zod (see `SuggestPage`, `BootstrapLoginPage`).
- **Markdown**: react-markdown + remark-gfm + rehype-sanitize for published answers.
- **Testing**: Vitest + Testing Library. Test files are co-located (`Thing.test.ts(x)`
  next to `Thing.ts(x)`).

## Auth

See [`../plans/05-auth-flow.md`](../plans/05-auth-flow.md) for the full design. In this
codebase:

- `src/auth/userManager.ts` — the single shared `oidc-client-ts` `UserManager` instance
  (Authorization Code + PKCE against the Cognito hosted UI). `null` in mock mode.
- `src/auth/AuthProvider.tsx` / `src/auth/useAuth.ts` — the `{ status, user, login, logout }`
  context every component reads via `useAuth()`.
- `src/auth/RequireAuth.tsx` — a layout route element that redirects to login when signed out.
- `src/auth/inviteStash.ts` — sessionStorage fallback for carrying an invite code across the
  OAuth round-trip (the primary carrier is `oidc-client-ts`'s `state` data).
- `src/auth/renewSession.ts` — token renewal, run shortly before expiry, on a reload with an
  expired ID token, and after a 401. Federated sessions use the refresh-token grant;
  bootstrap-login sessions use Cognito `REFRESH_TOKEN_AUTH` against the `admin-bootstrap`
  client (`src/auth/cognitoPasswordAuth.ts`).
- `src/routes/RequireMembership.tsx` / `RequireGroupAdmin.tsx` — group guards. They refetch
  `/config` once before redirecting (`useConfirmedAccess.ts`), so a just-granted membership
  or role isn't bounced by a stale cache.
- `src/pages/AuthCallbackPage.tsx` — handles `/auth/callback` (the OAuth redirect target).
- `src/pages/BootstrapLoginPage.tsx` — `/admin/bootstrap-login`, a dev-only
  username/password form against the `admin-bootstrap` Cognito client, for creating the
  very first group/admin before any invite exists. Only routed when `env.appEnv === "dev"`.
  Not available in mock mode (there's no real Cognito client to call).
- `src/api/client.ts` — attaches `Authorization: Bearer {idToken}` and an `x-correlation-id`
  header to every request; on a 401 it renews once and retries before signing the user out.

## Mocks

`src/api/mockTransport.ts` holds self-contained in-memory fixtures (users, groups,
newsletters) and is what `apiFetch` calls when `env.useMocks` is true. Mutations
(`PATCH /me`, `DELETE /groups/{g}/members/{u}`, `POST /invites/redeem`) write back into
that in-memory store, so the UI feels live across navigations within a session — reload
the tab to reset. Invite code `DEMO-JOIN-CODE` joins a demo group; any other code shows
the invalid-invite error.

`src/mocks/` is the **legacy** pre-M7 mock layer (`legacyQueries.ts`, `types.ts`, `api.ts`,
`data.ts`). It backs the pages later milestones haven't migrated yet (Candidates, Suggest,
Newsletter, Respond, GroupAdmin), which the router renders only in mock mode — against a
real API those routes show `PendingMilestonePage`. See
[`../plans/04-frontend-architecture.md` §16](../plans/04-frontend-architecture.md). Don't
build new features on it.

## Where types come from

`frontend/src/types/api.ts` is generated from [`../shared/openapi.yaml`](../shared/openapi.yaml)
via `openapi-typescript` (`../scripts/codegen_types.sh`). Never hand-edit it — API shapes
are imported from there (`import type { components } from "../types/api"`).
