# keys

Public key material checked into the repo. **Never commit private keys here.**

- `cf-signing.pub.pem` — CloudFront signing public key. Generated by the operator
  in Milestone 1 alongside a private key that is uploaded to Secrets Manager at
  `opennewsletter/cdn-signing/{env}`. CDK reads this file to create the
  CloudFront `PublicKey` + `KeyGroup`. See [`../../plans/05-auth-flow.md`](../../plans/05-auth-flow.md) §10
  and [`../../plans/01-infrastructure-cdk.md`](../../plans/01-infrastructure-cdk.md) §5.

Generate the keypair with:

```sh
openssl genrsa -out cf-signing.key 2048
openssl rsa -pubout -in cf-signing.key -out cf-signing.pub.pem
# upload cf-signing.key to Secrets Manager, then delete it locally
```
